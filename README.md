# Interactive Sales Dashboard using Microsoft Excel

## 📖 Project Overview

This project focuses on building an interactive Sales Dashboard using Microsoft Excel. The dashboard provides insights into sales performance using Pivot Tables, Pivot Charts, KPIs, and Slicers, allowing users to explore data dynamically.

## 🎯 Objective

Create an interactive dashboard to analyze sales performance and enable filtering by various categories.

## 🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## 📊 Dashboard Features

- Total Sales KPI
- Average Sales KPI
- Total Orders KPI
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Interactive Slicers
