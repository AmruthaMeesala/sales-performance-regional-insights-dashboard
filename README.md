# SkillCraft Technology - Data Science Internship Task 1

## Task
Build an interactive Sales Dashboard using Microsoft Excel.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## Dashboard Features
- Total Sales KPI
- Total Orders KPI
- Average Sales KPI
- Sales by Region
- Sales by Category
- Sales Trend
- Sales by Segment
- Top 10 Products
- Interactive Slicers

## Key Insights
- Technology generated the highest sales.
- West region recorded the highest revenue.
- Consumer segment contributed the largest share.
- Sales showed an increasing trend from 2015–2018.
